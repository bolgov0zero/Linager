# Linager: стартовый пакет для Claude Code

Это материалы для начала проекта Linager. Прочитай файлы в таком порядке:

1. `PROMPT.md` — главное задание. Начни с него.
2. `docs/decisions.md` — принятые решения, допущения и открытые вопросы.
3. `docs/design/ui-spec.md` — описание всех экранов и их поведения.
4. `docs/design/mockup/index.html` — рабочий макет интерфейса. Это эталон внешнего вида. Открой его в браузере (шрифты лежат рядом в `fonts/`), весь код стилей и логики лежит в одном файле.
5. `docs/design/screenshots/` — снимки всех экранов макета (светлая и тёмная темы, телефон).

## Что куда класть в репозитории

- `CLAUDE.md` положи в корень репозитория `linager`: Claude Code подхватит его автоматически.
- Папку `docs/` скопируй в корень репозитория как есть.
- Файлы `START_HERE.md` и `PROMPT.md` можно оставить в `docs/kickoff/`.

## Что в архиве

```
START_HERE.md            этот файл
PROMPT.md                задание для Claude Code
CLAUDE.md                правила проекта (в корень репозитория)
docs/
  decisions.md           решения, допущения, открытые вопросы
  design/
    ui-spec.md           спецификация интерфейса
    mockup/
      index.html         интерактивный макет (данные тестовые)
      fonts/             шрифты Medeo (лицензия OFL) и текст лицензии
    screenshots/         20 снимков экранов макета
```

## Важно

- Макет работает на тестовых данных и ничего не отправляет по сети. Его логику (откаты, раскатки, графики) нужно реализовать по-настоящему, но поведение и тексты брать из него.
- Шрифты Medeo распространяются по лицензии SIL OFL 1.1. Файлы шрифтов нужно хранить в репозитории рядом с текстом лицензии.
- Название GitHub-организации пока неизвестно. В макете и документах стоит заглушка `OWNER`.
