# Установка Linager

Поддерживаются Debian 12/13 и Ubuntu 22.04/24.04/26.04 (amd64, systemd). Агент также работает на arm64, например на Raspberry Pi 4 с Raspberry Pi OS 64-bit (Debian 12/13). 32-разрядные системы не поддерживаются, сервер на arm64 тоже.

## Быстрая установка

```bash
curl -fsSL https://raw.githubusercontent.com/bolgov0zero/linager/main/install.sh | sh
```

Команду нужно выполнять от root, иначе установщик завершится с ошибкой.

## Безопасный вариант: скачать, проверить, запустить

```bash
curl -fsSLO https://raw.githubusercontent.com/bolgov0zero/linager/main/install.sh
less install.sh                      # прочитайте скрипт
sudo sh install.sh
```

Скрипт очищает экран, проверяет систему, скачивает релиз, сверяет контрольную сумму и подпись minisign (ключ вшит в скрипт) и запускает мастер `linager install`.

## Мастер

Первый вопрос: что ставить, **Сервер** или **Клиент**.

### Сервер
Вопросы (порты обязательны, значений по умолчанию нет):

| Вопрос | Пояснение |
|---|---|
| Порт для клиентов | клиенты подключаются сюда напрямую по TLS |
| Доступ к админке | `Caddy на этом сервере` или `Свой обратный прокси` |
| Домен, порт HTTPS | только для Caddy: Let's Encrypt, нужны открытые порты 80 и 443 и DNS-запись |
| Порт админки (HTTP) | только для своего прокси: сюда обращается ваш прокси |
| Логин и пароль | пароль от 12 символов; пусто — сгенерировать и показать один раз |

Этапы: проверка системы, PostgreSQL (из репозитория ОС, только localhost, `scram-sha-256`), база и роль со случайным паролем, конфигурация `/etc/linager/server.yaml` (права 600, владелец `linager`) и ключи, администратор, Caddy (если выбран), служба `linager-server`, проверка запуска. Ход установки пишется в `/var/log/linager-install.log`.

В режиме «Свой обратный прокси» мастер ничего не ставит и не настраивает, только запрашивает порты. Админка слушает `0.0.0.0:<порт>`, заголовки `X-Forwarded-*` принимаются от любого адреса (список сужается в «Настройки» → «Доступ к админке» → «Доверенные прокси»; значение `admin.trusted_proxies` в `server.yaml` действует, пока там ничего не сохранено). Порт админки открыт напрямую: ограничьте его файрволом. Примеры прокси: [proxy.md](proxy.md).

В итоге показываются адрес админки, отпечаток сертификата клиентского порта и готовая команда установки клиента.

### Клиент
Вопросы: адрес сервера `host:порт клиентов` и подтверждение отпечатка (или флаг `--fingerprint`). Затем мастер показывает **ключ** `XXXX-XXXX` и **код сверки**. Введите ключ в админке («+ Сервер», блок «Ждут подтверждения») и убедитесь, что коды совпадают. После подтверждения запускается служба `linager-agent`. Адрес, порт и отпечаток для этого вопроса можно взять в админке: «+ Сервер», блок «Данные для подключения клиента» (адрес берётся из адресной строки браузера, кнопка копирует `адрес:порт`).

## Без вопросов (автоматизация)

```bash
sudo linager install server --no-tui --agent-port 9443 --admin-mode proxy --admin-port 8080 --admin-user admin
sudo linager install server --no-tui --agent-port 9443 --admin-mode caddy --domain linager.example.com
sudo linager install agent  --no-tui --server 10.0.0.5:9443 --fingerprint SHA256:...
```

Без терминала или с `--no-tui` вопросы не задаются: все обязательные параметры берутся из флагов. `--lang ru|en` выбирает язык, `--force` разрешает повторную установку, `--admin-password-file` задаёт пароль из файла.

## Удаление клиента
В админке: карточка сервера, «Удалить». Можно сразу удалить агента с хоста. Вручную на хосте: `sudo linager agent uninstall --purge`.
