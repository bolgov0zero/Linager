Журнал показывает, какие пакеты и какие правила сработали. Файрвол ничего не пишет сам: нужно включить запись для правил, которые вас интересуют.

1Включите запись для правил ниже. К правилу добавляется log с меткой.
2Применяйте, как обычно: подтверждение и откат через 30 секунд.
3Срабатывания появятся здесь через несколько секунд. Хранятся 7 дней.
Запись у правил с большим трафиком быстро растёт: для них включён лимит, не больше 5 записей в секунду.
ip saddr @mgmt meta l4proto tcp limit rate 5/second log prefix "lg:input:3 " counter accept
Записи берутся из журнала ядра (метка lg:), поэтому история доступна и после перезагрузки агента.
