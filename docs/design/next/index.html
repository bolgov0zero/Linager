Как это читать

«Разрешён правилом» значит, что в input есть явное правило. «Нет правила, открыт всем» значит, что процесс слушает на всех интерфейсах, а файрвол пропускает трафик политикой. Адреса 127.0.0.1 и сети Docker наружу не видны.

Только в макете, показать состояние:

адресов подбирали пароль

fail2ban следит за журналом SSH и автоматически блокирует адреса, которые подбирают пароль. Это снимет большую часть шума и нагрузки.

Насколько строго блокировать

Свой адрес 198.51.100.20 и сеть 127.0.0.0/8 не блокируются. Порог можно изменить позже.

Будет установлен пакет и включена защита SSH с порогом «Обычно»:

apt-get install -y fail2ban systemctl enable --now fail2ban # /etc/fail2ban/jail.d/linager.conf [sshd] maxretry=5 findtime=10m bantime=1h ignoreip=127.0.0.1/8 198.51.100.20

Действие пишется в журнал аудита. Если менеджер пакетов занят, агент подождёт до двух минут.

Повторные нарушители

Не блокировать

127.0.0.0/8198.51.100.20 · ваш адрес10.20.0.0/24

Ваш текущий адрес всегда остаётся в исключениях.

Показать файл настроек
[sshd] enabled = true maxretry = 5 findtime = 10m bantime = 1h bantime.increment = true bantime.factor = 2 bantime.maxtime = 7d ignoreip = 127.0.0.1/8 198.51.100.20 10.20.0.0/24
fail2ban перечитает настройки, текущие блокировки сохранятся. Изменение пишется в журнал аудита.
