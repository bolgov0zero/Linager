Linager

Макет вкладки «Пользователи» (новая вкладка группы «Сеть и защита», модуль агента users). Данные вымышленные. Работают: фильтры и поиск, строка открывает свойства учётной записи в окне, «Добавить», «Удалить»; «Терминал» открывает плавающее окно (перетаскивание, размер, свернуть, развернуть, закрыть, панель окон внизу слева), можно открыть несколько. Пометка «новое» отмечает то, чего в панели ещё нет.
