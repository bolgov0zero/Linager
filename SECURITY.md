# Security policy / Политика безопасности

**EN.** Please report vulnerabilities privately through GitHub: *Security → Report a vulnerability* in this repository. Do not open public issues for security problems. We aim to acknowledge a report within 3 working days. Supported: the latest release.

**RU.** О найденных уязвимостях сообщайте приватно через GitHub: вкладка *Security → Report a vulnerability* этого репозитория. Не создавайте публичные issues. Подтверждение в течение 3 рабочих дней. Поддерживается последний релиз.

Details of the design / описание устройства защиты: [docs/en/security.md](docs/en/security.md), [docs/ru/security.md](docs/ru/security.md).
