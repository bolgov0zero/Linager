# Введение

Linager — открытая система управления серверами на Debian, Ubuntu и Windows: сервер с веб-админкой и лёгкие агенты на управляемых серверах.

## Что вы получаете

- Метрики в реальном времени каждые 5 секунд и история до 360 дней.
- Веб-терминал, файловый менеджер, службы systemd, процессы и журналы.
- Обновления apt, правка сети и файрвола с автоматическим откатом, Docker.
- Агент для Windows: та же страница сервера с удалённым рабочим столом в браузере, службами, пользователями и Windows Update.
- Правка контейнера Docker, игнор обновлений отдельных пакетов и контейнеров, отдельная мобильная вёрстка.
- Роли, 2FA, passkey и журнал аудита всех действий администратора.
- Контроль доступа к админке: белый или чёрный список по реальному адресу клиента, доверенные прокси и журнал обращений.

::: tip Один бинарник
Один и тот же `linager` — это сервер или агент. Роль выбирается при установке.
:::

## Как это устроено

Сервер хранит данные в локальном PostgreSQL и отдаёт админку. Каждый агент открывает исходящее соединение с сервером по взаимному TLS, поэтому на управляемых серверах не нужен открытый входящий порт. Правки сети и файрвола применяются с таймером отката на 30 секунд, который работает на агенте.

### Поддерживаемые системы

| Система | Сервер | Агент |
|---|---|---|
| Debian 12, 13 | amd64 | amd64, arm64 |
| Ubuntu 22.04, 24.04, 26.04 | amd64 | amd64, arm64 |
| Windows 10 / 11, Server 2016+ | нет | amd64 (MSI) |

Агент работает и на Raspberry Pi 4 с 64-разрядной ОС. Агент для Windows описан в разделе [Агент для Windows](windows).

## Что дальше

Начните с [установки](install), затем добавьте первый сервер одним из трёх способов («+ Сервер» в админке): запустите тот же установщик на нём, выберите **Клиент** и подтвердите код сверки; либо создайте **ссылку установки** и выполните одну команду на новом сервере; либо дайте админке поставить агента **по SSH**. Когда установка закончится, меню Linager откроется само ([меню в терминале](menu)). Чтобы поставить админку за обратный прокси, читайте [Обратный прокси](proxy), чтобы ограничить доступ к ней — [Доступ к админке](access).
