# Linager

Открытая система управления серверами на Debian: сервер с админкой и агенты на управляемых серверах. Подробности: `docs/kickoff/PROMPT.md` (или `PROMPT.md` из стартового пакета), `docs/decisions.md`, `docs/design/ui-spec.md`.

## Правила
- Язык кода, идентификаторов, комментариев, коммитов: английский. Документация и интерфейс: русский основной, английский второй (всё через i18n).
- Go, один бинарник `linager` с ролями server и agent. Платформы: Debian 12 и 13, Ubuntu 22.04, 24.04 и 26.04 LTS (семейство apt/systemd), amd64; arm64 только для агента (Raspberry Pi 4 с 64-разрядной ОС). Windows x64 (10/11, Server 2016+): только агент, beta (docs/ru/windows.md).
- PostgreSQL только локальный. Миграции только вперёд.
- Эталон интерфейса: `docs/design/mockup/index.html` и `docs/design/screenshots/`. Не менять стиль без согласования.
- Шрифты Medeo (OFL) хранить локально вместе с текстом лицензии, не подключать с CDN.
- Откат сети и файрвола выполняет агент (таймер 30 с), не сервер.
- Секреты только с правами 600. Опасные действия требуют подтверждения. Все действия администратора пишутся в журнал аудита.
- Работай этапами из PROMPT.md, по одному за раз. Перед реализацией этапа покажи план и дождись подтверждения.
- К каждому изменению: тесты и обновление документации.
